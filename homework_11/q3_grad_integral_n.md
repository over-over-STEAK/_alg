# 多變數微分、最小值與超體積

AI 使用：有，ChatGPT 協助程式、測試與文件。

## 方法

使用中央差分求梯度，梯度下降求平方和最小值，並用多維中點黎曼和求超體積。固定學習率只適用於合適的函數，不保證一般函數全域最小值。

## 測試模板

每題使用 `test()` 與 `check(name, actual, expected, tolerance)` 比較理論值及絕對誤差。

```bash
python q3_grad_integral_n.py
```
