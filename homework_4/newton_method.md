# 第四週習題：牛頓迭代法求解方程式

## 一、題目與目的

使用 Python 與牛頓迭代法，求解以下方程式的實數根：

$$
x^3-2x-5=0
$$

本實驗從初始值 2.0 開始，透過反覆修正近似值，觀察數值如何接近答案，並使用前後差距與方程式殘差判斷是否達到指定精度。

## 二、迭代法的概念

迭代法會將上一輪的計算結果作為下一輪的輸入。本題包含三個主要要素：

| 要素 | 設定 |
| --- | --- |
| 初始猜測 | `x0 = 2.0` |
| 更新公式 | 牛頓法：$x_{n+1}=x_n-f(x_n)/f'(x_n)$ |
| 停止條件 | 前後差距與絕對殘差皆小於 $10^{-8}$；最多更新 100 次 |

達到最大迭代次數只代表停止計算，不代表已經收斂。

## 三、數學公式推導

定義原函數：

$$
f(x)=x^3-2x-5
$$

對它微分：

$$
f'(x)=3x^2-2
$$

牛頓法利用目前位置的切線與 x 軸的交點，作為下一個近似值。切線方程式為：

$$
y=f(x_n)+f'(x_n)(x-x_n)
$$

令 $y=0$，在導數不為零時整理得到：

$$
x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}
$$

代入本題函數與導數：

$$
\boxed{x_{n+1}=x_n-\frac{x_n^3-2x_n-5}{3x_n^2-2}}
$$

也可合併成：

$$
x_{n+1}=\frac{2x_n^3+5}{3x_n^2-2}
$$

## 四、第一次迭代的計算

設定 $x_0=2$：

$$
f(2)=2^3-2(2)-5=-1
$$

$$
f'(2)=3(2^2)-2=10
$$

因此：

$$
x_1=2-\frac{-1}{10}=2.1
$$

下一輪以 2.1 作為輸入，持續套用相同公式。

## 五、完整 Python 程式

將以下內容存成 `newton_method.py`：

```python
def f(x):
    return x**3 - 2*x - 5


def df(x):
    return 3*x**2 - 2


def newton_method(x0=2.0, tolerance=1e-8, max_iterations=100):
    x = x0

    for n in range(1, max_iterations + 1):
        derivative = df(x)

        if abs(derivative) < 1e-12:
            print("導數太接近 0，無法繼續計算。")
            return None

        next_x = x - f(x) / derivative
        print(f"第 {n} 次迭代：x = {next_x:.10f}")

        if abs(next_x - x) < tolerance and abs(f(next_x)) < tolerance:
            print(f"\n近似解：{next_x:.10f}")
            print(f"方程式殘差：{f(next_x):.10e}")
            print(f"迭代次數：{n}")
            return next_x

        x = next_x

    print("達到最大迭代次數，仍未收斂。")
    return None


newton_method()
```

以上保留原程式的計算邏輯。這是一個針對本題的純量牛頓法實作，沒有使用先前的 `generic_iterator` 框架。

## 六、程式重點說明

| 程式內容 | 功能 |
| --- | --- |
| `f(x)` | 計算原方程式的值 |
| `df(x)` | 計算導數，也就是目前位置的斜率 |
| `x = x0` | 設定初始近似值 |
| `for n in range(...)` | 重複執行更新步驟 |
| `abs(derivative) < 1e-12` | 導數太接近零時中止，避免不穩定除法 |
| `next_x = x - f(x) / derivative` | 套用牛頓更新公式 |
| `x = next_x` | 將這一輪結果交給下一輪 |
| `return next_x` | 達標後回傳近似解 |
| `return None` | 本次計算未取得符合條件的結果 |

### 兩個停止判斷

第一個條件檢查前後差距：

$$
|x_{n+1}-x_n|<10^{-8}
$$

第二個條件檢查方程式的絕對殘差：

$$
|f(x_{n+1})|<10^{-8}
$$

程式使用 `and`，所以必須同時滿足兩個條件才停止。只檢查數值變化很小，可能把數值停滯誤認為求解成功。

輸出的「方程式殘差」是有正負號的 $f(x)$；停止判斷使用的是它的絕對值 $|f(x)|$。

## 八、執行結果與觀察

使用預設參數，依相同更新公式與停止條件以 Python 核對，結果如下：

```text
第 1 次迭代：x = 2.1000000000
第 2 次迭代：x = 2.0945681211
第 3 次迭代：x = 2.0945514817
第 4 次迭代：x = 2.0945514815

近似解：2.0945514815
方程式殘差：-8.8817841970e-16

```

不同浮點數運算環境可能讓最後幾位略有差異。

| 更新次數 | 近似值 | 有號殘差 $f(x)$ |
| ---: | ---: | ---: |
| 1 | 2.1000000000 | 6.1000000000e-02 |
| 2 | 2.0945681211 | 1.8572317327e-04 |
| 3 | 2.0945514817 | 1.7397612240e-09 |
| 4 | 2.0945514815 | -8.8817841970e-16 |

### 為什麼第 3 次還沒有停止？

第 3 次的絕對殘差已小於 $10^{-8}$，但與第 2 次的差距約為 $1.66\times10^{-5}$，還沒有符合前後差距的要求，因此繼續到第 4 次。

### 結果代表什麼？

近似解為：

$$
\boxed{x\approx2.0945514815}
$$

代入原式後，$x^3-2x-5$ 很接近零。`e-16` 表示乘以 $10^{-16}$。列印的殘差使用程式內保留的完整浮點數計算；若只拿顯示到小數點後 10 位的數值手動代入，殘差不會完全相同。

殘差接近零表示方程式近似成立，但殘差不是與真實根的絕對誤差，兩者不能直接視為相同。

## 九、與不動點迭代的關係

牛頓法也可以寫成不動點迭代形式：

$$
x_{n+1}=g(x_n)
$$

其中：

$$
g(x)=x-\frac{f(x)}{f'(x)}
$$

在 $f'(r)\ne0$ 時，方程式的根 $r$ 滿足 $g(r)=r$，所以它也是牛頓更新函數的不動點。

對本題，根附近的導數不為零，且函數光滑。從足夠靠近根的初始值開始，牛頓法具有二階收斂；這不代表任意初始值都保證成功。本次設定 $x_0=2$ 的實際計算成功達標。
