# 遞迴與函數式程式設計作業

本作業使用 Python 完成河內塔、符號數學式微分，以及禁止迴圈的泡沫排序。

## 檔案說明

| 檔案名稱 | 功能 | 實作方式 |
| --- | --- | --- |
| `hanoi_recursive.py` | 河內塔遞迴版本 | 函數呼叫自己，拆解成較小問題 |
| `hanoi_iterative.py` | 河內塔非遞迴版本 | 使用堆疊與 `while` 處理待完成工作 |
| `sym_diff.py` | 符號數學式微分 | 遞迴走訪運算式結構並套用微分規則 |
| `bubble_sort_recursive.py` | 自製 map、filter、reduce 與泡沫排序 | 使用遞迴取代迴圈 |

## 執行環境與方式

使用 Python 3.9 或更新版本。程式只使用 Python 標準函式庫，不需要額外安裝套件。

將四個 Python 檔案與本 README 放在同一個資料夾，在該資料夾開啟終端機，分別執行：

```bash
python hanoi_recursive.py
python hanoi_iterative.py
python sym_diff.py
python bubble_sort_recursive.py
```

部分系統需要將 `python` 改成 `python3`。

## 第一題：河內塔

### 題目

請分別使用遞迴與禁止遞迴兩種方式解決河內塔問題。

### 搬動規則

1. 每次只能移動一個圓盤。
2. 每次只能移動柱子最上方的圓盤。
3. 大圓盤不能放在小圓盤上方。
4. 將所有圓盤從 A 柱搬到 C 柱，B 柱作為輔助。

### 遞迴版本：hanoi_recursive.py

主要函數：

```python
hanoi_recursive(n, source="A", auxiliary="B", target="C")
```

將搬動 n 個圓盤拆成三個步驟：

1. 將上方 n−1 個圓盤從起點搬到輔助柱。
2. 將第 n 個圓盤從起點搬到終點。
3. 將輔助柱上的 n−1 個圓盤搬到終點。

當 n 等於 0 時直接返回，作為遞迴終止條件。n 應為非負整數。

### 非遞迴版本：hanoi_iterative.py

主要函數：

```python
hanoi_iterative(n, source="A", auxiliary="B", target="C")
```

用 `stack` 儲存尚未完成的工作，使用 `while` 逐一取出處理。`solve` 表示需要拆解的搬運問題，`move` 表示實際搬動一個圓盤。

因為堆疊具有後進先出的特性，三個工作必須按照相反順序放入，才能依照正確順序執行。此版本沒有函數自我呼叫，符合禁止遞迴的要求。

### 範例結果

兩個版本以 3 個圓盤執行，預期輸出相同：

```text
圓盤 1：A → C
圓盤 2：A → B
圓盤 1：C → B
圓盤 3：A → C
圓盤 1：B → A
圓盤 2：B → C
圓盤 1：A → C
```

最少搬動次數為 `2**n - 1`。兩個版本的時間複雜度皆為 O(2^n)，輔助空間皆為 O(n)。

## 第二題：遞迴符號微分

使用遞迴實作 `sym_diff(expr)`，輸入數學式字串，回傳微分後的數學式字串。

### 檔案

`sym_diff.py`

### 實作原理

使用 `ast.parse(expr, mode="eval")` 將輸入字串解析成抽象語法樹。`ast` 負責解析，微分由自製的 `diff(node)` 完成，沒有使用現成符號微分函式庫。

遇到加減乘除時，遞迴計算左右子式的導數，再依據運算種類組合結果。遇到常數或變數時直接回傳，作為終止條件。

微分變數固定為 `x`，其他變數名稱視為與 x 無關的常數。

| 運算式 | 微分結果 |
| --- | --- |
| 常數 c | 0 |
| x | 1 |
| u + v | u′ + v′ |
| u − v | u′ − v′ |
| u × v | u′v + uv′ |
| u / v | (u′v − uv′) / v² |
| u 的 n 次方 | n × u 的 n−1 次方 × u′，n 為數值常數 |

### 使用範例

```python
print(sym_diff("x**3 + 2*x + 5"))
print(sym_diff("(x + 1)**2"))
print(sym_diff("x / (x + 1)"))
```

三個結果的數學意義分別為：

```text
3*x**2 + 2
2*(x + 1)
1/(x + 1)**2
```

以上為人工化簡後的等價式。此作業採用的程式版本不自動化簡，實際輸出會包含括號、乘以 1 或加上 0 等項目。

### 支援範圍

- 支援數值常數、變數、正負號、加減乘除。
- 支援數值常數次方，包括負數次方。
- 乘方請使用 `**`，例如 `x**3`，不要使用 `^`。
- 不支援 `sin(x)`、`log(x)` 或 `x**x` 等需要額外規則的運算式。
- 除法與次方的微分結果應在原式及微分規則成立的定義域內使用。

## 第三題：自製高階函數與遞迴泡沫排序

自製 map、filter、reduce 函數，並在禁止使用迴圈的條件下完成泡沫排序。

`bubble_sort_recursive.py`

### 自製函數

| 函數 | 功能 | 遞迴終止條件 |
| --- | --- | --- |
| `my_map(func, items)` | 對每個元素套用函數，回傳新列表 | 列表為空時回傳 `[]` |
| `my_filter(predicate, items)` | 保留符合條件的元素 | 列表為空時回傳 `[]` |
| `my_reduce(func, items, initial)` | 依序合併元素，回傳累積結果 | 列表為空時回傳累積值 |

三個函數都以遞迴處理列表，不使用內建 `map`、`filter` 或 `reduce`。

### 泡沫排序原理

`bubble_pass(items)` 使用自製的 `my_reduce` 執行一輪比較。每次將較小值加入結果，較大值保留到下一次比較，使最大值最後移到尾端。

`bubble_sort(items)` 再遞迴排序剩餘元素，並將該輪最大值接到排序結果後方。當列表長度小於或等於 1 時，直接回傳列表的複本。

排序主要使用 `my_reduce`；`my_map` 與 `my_filter` 另外透過範例展示功能。

整份第三題程式沒有 `for`、`while` 或列表推導式，也沒有呼叫內建 `sorted`。

```text
map： [2, 4, 6, 8]
filter： [2, 4]
reduce： 10
排序前： [5, 1, 4, 2, 8]
排序後： [1, 2, 4, 5, 8]
```

### 複雜度與限制

泡沫排序的比較次數為 `n*(n-1)/2`，因此比較次數是 O(n²)。

本版本為了方便理解，使用列表切片與串接。這些操作需要複製元素，因此整體實作的最壞時間可達 O(n³)，不能直接把完整 Python 程式的執行時間視為 O(n²)。

Python 的遞迴深度有限，此版本適合小型資料與課堂示範。

## 學習重點

1. 遞迴需要明確的終止條件，且每次呼叫都必須朝終止條件前進。
2. 可使用堆疊保存工作狀態，把遞迴流程改寫成迭代流程。
3. 符號微分可以透過運算式的樹狀結構，逐層拆解與組合。
4. map、filter、reduce 可以自行以遞迴實作。
5. 分析複雜度時，除了比較次數，也要考慮列表複製等實際操作成本。
