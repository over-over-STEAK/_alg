# 計算 2ⁿ：四種 Python 方法比較

本作業根據提供的程式截圖整理，計算相同的數值 $2^n$，比較內建次方、雙分支遞迴、單分支遞迴及記憶化遞迴。

> 這是「計算 2ⁿ 的演算法比較」，與前一份「四個 T(n) 遞迴式求解」是不同題目。程式回傳的值與程式的執行成本必須分開分析。

## 檔案說明

| 檔案 | 內容 |
|---|---|
| `power2n.py` | 執行四種方法、計時並驗算 |
| `power2n1.py` | Python 內建 `2 ** n` |
| `power2n2a.py` | 兩次遞迴相加 |
| `power2n2b.py` | 一次遞迴乘以 2 |
| `power2n3.py` | 字典快取的記憶化遞迴 |

所有函式的輸入前提為非負整數；主程式檢查輸入並限定 0～200。遞迴函式不適合直接用非常大的 n，以免超過 Python 的遞迴深度限制。

## 1. 內建次方

```python
def power2n_1(n):
    return 2 ** n
```

程式最簡潔，適合直接計算。只有一行不代表時間複雜度是 O(1)：Python 整數可以隨結果增大，實際成本與大整數次方的實作有關。本作業不將內建運算的精確複雜度武斷列為常數。

## 2a. 雙分支遞迴

```python
def power2n_2a(n):
    if n == 0:
        return 1
    return power2n_2a(n - 1) + power2n_2a(n - 1)
```

利用 $2^n=2^{n-1}+2^{n-1}$，但是兩個相同的子問題會各自重新計算。

以每次函式進入計為一次呼叫，包含最初呼叫及基底情況：

$$C(0)=1,\qquad C(n)=2C(n-1)+1$$

$$C(n)=2^{n+1}-1$$

因此在基本運算視為常數的模型下，時間為 $O(2^n)$，最大遞迴深度為 $n+1$，堆疊空間為 $O(n)$。

當 n=100，呼叫次數為 2535301200456458802993406410751，不適合實際執行。獨立檔案改以 n=20 示範；比較程式在 n>20 時跳過這一項。

## 2b. 單分支遞迴

```python
def power2n_2b(n):
    if n == 0:
        return 1
    return 2 * power2n_2b(n - 1)
```

雖然結果相同，但只有一次遞迴呼叫，沒有重複計算：

$$C(0)=1,\qquad C(n)=C(n-1)+1=n+1$$

在基本運算視為常數的模型下，時間為 $O(n)$，堆疊空間為 $O(n)$。

**乘上 2 是對結果做乘法，不代表呼叫函式兩次。**

## 3. 記憶化遞迴

```python
def power2n_3(n, memo=None):
    if memo is None:
        memo = {}
    if n == 0:
        return 1
    if n in memo:
        return memo[n]
    memo[n] = power2n_3(n - 1, memo) + power2n_3(n - 1, memo)
    return memo[n]
```

第一次算出某個 n 的結果後，存入字典；第二次遇到同一個 n 就直接回傳快取。

與截圖中的全域 `memo = {}` 相比，本版本每次頂層呼叫會使用新的字典，避免前一次執行的快取影響計時。遞迴內部仍共用同一份字典。

在初始快取為空的情況下，每個正整數狀態僅展開一次，總呼叫次數（包含快取命中及 n=0）為 $2n+1$。

在基本運算與字典平均查找視為常數的模型下，時間為 $O(n)$，快取與堆疊的項目數皆為 $O(n)$。

## 比較總表

| 方法 | 初始無快取時的函式呼叫次數 | 教學用時間分析 | 額外空間分析 |
|---|---|---|---|
| 內建次方 | 外層函式 1 次，內部成本另計 | 取決於大整數實作，不能由一行判為 O(1) | 取決於實作 |
| 雙分支遞迴 | $2^{n+1}-1$ | $O(2^n)$ | $O(n)$ 層堆疊 |
| 單分支遞迴 | $n+1$ | $O(n)$ | $O(n)$ 層堆疊 |
| 記憶化遞迴 | $2n+1$ | $O(n)$ | $O(n)$ 個快取項目及堆疊 |

上述線性時間採用基本算術為常數的教學模型。嚴格計算 Python 大整數的位元成本時，$2^n$ 有 n+1 個二進位位元，運算及儲存不能一律視為常數。例如記憶化保存 $2^1$ 至 $2^n$，其數值內容合計需要 $\Theta(n^2)$ 位元，而非只有 O(n) 位元。

## 執行方式

不需要安裝額外套件。Windows：

```bash
py power2n.py
```

預設 n=100，雙分支遞迴會跳過。要比較全部四種方法：

```bash
py power2n.py 20
```

也可以分別執行：

```bash
py power2n1.py
py power2n2a.py
py power2n2b.py
py power2n3.py
```

macOS／Linux 可將 `py` 換成 `python3`。

## 結論

四種方法計算的數值相同，但執行效率不同。雙分支遞迴的問題是重複計算；單分支遞迴直接消除重複呼叫，記憶化則透過儲存結果避免重算。若只是需要算出 2ⁿ，內建次方最簡潔；其他版本適合用來觀察遞迴與快取的差異。
